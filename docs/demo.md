# 课堂演示与验收

## 演示前准备

按 [根目录 README](../README.md) 安装依赖和本地向量模型，在 VS Code 或通过 `start.bat` 启动。推荐配置是 ChatGPT 会员生成加本机 `qwen3-embedding:0.6b`；本次真实验收使用的生成模型为 `gpt-6.1-sol`，实际可用模型以当前账户列表为准。

使用自己的知微账户，在“模型与检索状态”中通过 **Continue with ChatGPT** 完成授权，选择可用模型，再检查生成与向量模型。提前完成模型下载和授权；主动模型检查及后续问答会使用会员额度。状态中仅有配置、账号连接或模型名称，均不能替代实际检查。

准备 `sample_docs/` 的三个教学文件。它们包含虚构计划，不是访谈或研究数据；“青竹-27”“2026 年 11 月 6 日”“3 位同学”和计划中的 20 题评估集均属于样例内容，不能写成已经实施的用户评测。

## 3–5 分钟闭环演示

| 时间 | 操作 | 观察结果 / 对应需求 |
| --- | --- | --- |
| 0:00–0:30 | 登录知微，展示模型检查结果，创建“软件工程学习资料”库 | 账户、库与模型状态分开；US-01、US-02 |
| 0:30–1:15 | 批量上传三份样例，或点击“导入示例” | 文件、片段数及向量索引状态可见；待全部就绪再提问；US-03 |
| 1:15–2:00 | 问“青竹-27 的里程碑日期是什么？”，点击引用 | 检查本条是“AI 生成”“语义向量检索”，再核对计划原文；US-04 |
| 2:00–2:30 | 同一会话追问“它的核心闭环包含哪些步骤？” | 追问结合当前会话，并分别显示证据；US-04 |
| 2:30–3:00 | 问“项目的预算是多少？”或资料外的天气问题 | 样例未提供预算和实时天气；应说明资料不足，不能编造数值和引用；US-04 |
| 3:00–3:30 | 新建会话，再打开刚才的历史；刷新页面 | 同一知识库的消息及实际回答模式仍在；US-05 |
| 3:30–4:15 | 重复上传样例，再上传不支持的格式 | 同库去重，逐文件错误反馈，不把失败文件当索引成功；US-03 |
| 4:15–5:00 | 展示验证记录与局限 | 区分真实模型、回归、边界和 UI 检查；说明尚未完成真人体验与性能评测 |

演示用时只是流程安排，首次下载、索引和模型响应的实际时长可能更长。若向量未就绪，先查看文档错误、检查模型，再重建当前库索引。

若本条显示“原文摘录”或“生成失败 · 已降级”，应如实展示故障与可用来源，不把它计为生成通过。显式选择 `RAG_PROVIDER=local` 可演示离线词法摘录。推荐会员方案的向量化在本机执行，但问题、检索片段及必要历史会发送给 OpenAI。

## 验收口径

| 验收项 | 合格条件 | 验证层 |
| --- | --- | --- |
| 登录与资源隔离 | 未登录及跨账户访问被拒绝，库和会话不混用 | 后端回归；真实验收另测库隔离 |
| 文档导入 | 支持可解析的 PDF / MD / TXT；有效文件入库，损坏、空白或不支持格式逐文件反馈 | 回归与容量边界 |
| 语义向量 | 保存真实嵌入、模型指纹和索引状态；更换模型后不能混用旧向量 | 回归与真实模型 |
| 生成与多轮 | 同义、跨文档与指代问题返回 `llm`、`dense`、`validated`，并核对结论内容 | 有限真实模型案例 |
| 引用 | 结论绑定当前库片段，引文逐字存在，来源可查；无效引文不能作为生成成功 | 回归与真实模型 |
| 拒答与故障 | 未知事实、要求编造时不捏造出处；模型失败明确降级 | 真实拒答案例；故障主要用模拟回归 |
| 删除与持久化 | 已删除片段不参与新检索；保存的资料、向量和历史可恢复 | 回归；真实验收另测删除后拒答 |
| 模型与 UI 状态 | 配置不等于连通；手机与桌面能查看模型、索引和错误状态 | 状态回归与独立浏览器检查 |
| 用户体验与性能 | 同学使用真实资料，记录查找耗时、核对准确性和失败原因 | 待实施 |

在项目根目录运行 `python -m unittest discover -s tests -v` 和 `python tools/check_boundaries.py`；真实模型工具的范围见 [tools/README.md](../tools/README.md)。本次各层结果与样本限制见 [RAG 修订验收](rag-validation.md)，不要把它们相加为“问答准确率”。

## 答辩说明

核心假设是学生能更快找到并核对学习资料。运行演示证明当前流程可执行；验证这一假设还需要真人对照使用和独立质量评估。逐字引文检查不等于概括正确，更不构成零幻觉保证。

代码中的语义向量保存在 SQLite，Chroma 只保留适配入口，尚未部署。课程提交另需核对 [报告与原型](../coursework/README.md)，补齐真实组员信息、访谈依据、实测记录与提交信息；运行界面和工程文档不能代替这些材料。
