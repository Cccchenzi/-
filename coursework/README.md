## 需求范围与完成状态

五个 Must 用户故事保持一致：US-01账号，US-02知识库，US-03批量导入与语义向量化，US-04基于语义检索证据的生成、追问与出处，US-05会话历史。

**语义向量化和RAG生成均属于本轮Must。** 默认方案为ChatGPT会员OAuth登录加本地Ollama嵌入。官方会员授权已经完成，实际使用 `gpt-6.1-sol` 和 `qwen3-embedding:0.6b` 的11项真实RAG检查全部通过。工程实现了稠密向量持久化、模型变更后重建、语义检索、结构化生成调用与逐字引文校验；TF-IDF与原文摘录仅是明确标注的故障降级路径。核心合成验收已通过，复杂真实资料和更广问题范围仍需持续评估。

US-06的Should范围是维护配置状态、回答模式和降级原因的可观察性与维护增强；US-07的Could范围仅为Chroma后端接入，目前保留可替换接口。语义嵌入已经纳入Must，并非后续可选升级。

资料解析及默认语义嵌入在本机进行；会员生成会发送问题、检索片段和必要上下文给ChatGPT，需确认资料授权。授权令牌在Windows由DPAPI保护，不返回前端；公开仓库不包含令牌或用户资料。

## 原型演示

双击 `prototype.html`，或在浏览器打开该文件。它不依赖服务器，不读取真实文件，不调用模型，不提供真实身份认证，也不将内容保存到磁盘。演示数据只保留在当前页面内存中，刷新或点击“重置全部演示”后清空。

| 页面 | 内容 | 需求 |
| --- | --- | --- |
| P01 入口与身份 | 选择演示账户A/B，模拟登录成功或失败 | US-01 |
| P02 知识库 | 创建、选择、删除和空状态 | US-02 |
| P03 批量上传 | 模拟有效文件、部分失败及输入边界 | US-03 |

| P05 来源核对 | 来源文件、原文片段及位置 | US-04 |
| P06 会话历史 | 当前库的历史列表、重开、新建与删除 | US-05 |
| P07 边界与异常 | 资料不足、模型失败、输入错误、空库和账户隔离入口 | US-01～US-05 |

推荐路径：选择演示账户A → 创建“示例资料库A” → 模拟上传3个有效文件 → 填入“里程碑安排”并发送 → 点击`[1]`进入P05核对 → 追问“该怎么验收” → P06重开历史 → P07演示拒答和回退。这里使用“示例项目甲”的合成资料，与工程目录中的“青竹-27”样例不是同一套演示内容。

**自动77项、边界14项、真实RAG 11项和UI 13项分别统计，不合并为unittest数量。** 真实RAG的11项含连接、上传和隔离等流程检查，并非11个问答质量样本。真实嵌入单例另记，不是总体准确率基准。首次嵌入请求29.42秒包含冷启动，不能据此声称预热检索性能达标。原型中的资料、回答与行号均为演示；报告中的性能和效率阈值仍是拟议目标。

真实生成核对了三例：“练习成果”同义提问回答教务系统提交；跨两份文档回答提交渠道及魏老师验收；“他要求展示多久”追问回答四分钟。四条生成结论均带对应原文的连续逐字引文，未发现该轮事实或引用错误。未知预算和诱导编造预算均拒答且不附伪造引用。验收只使用新建合成知识库，完成后已清理，授权凭据始终留在原应用的加密存储中。有限用例通过不保证所有问题正确或零幻觉。
