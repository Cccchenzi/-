## 原型演示

用浏览器打开 `prototype.html`，选择演示账户 A，按以下路径操作：

P01 进入 → P02 创建知识库 → P03 模拟上传 → P04 提问与追问 → P05 核对来源 → P06 重开历史 → P07 查看异常反馈。

原型使用固定演示数据，不读取真实文件、不认证真实账户、不调用模型；刷新页面会清空演示状态。运行中的应用演示见[使用演示](../docs/demo.md)。

需求报告讲解与原型演示各安排 3–5 分钟，讲解要点和需求编号对应关系见报告附录。个人信息字段保留空白，用户验证计划尚未实施。
