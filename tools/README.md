# 补充边界检查

`check_boundaries.py` 是可独立运行的 14 项精确边界检查，不属于 `tests/` 中的 28 项 `unittest`，两组结果应分别记录。

在项目根目录安装依赖后运行：

```powershell
.\.venv\Scripts\python.exe tools/check_boundaries.py
```

结果 JSON 默认保存在系统临时目录的新文件中，终端显示具体位置。所有检查通过时退出码为 `0`，存在不符合预期的结果时为 `1`。可指定结果位置，例如：

```powershell
.\.venv\Scripts\python.exe tools/check_boundaries.py --output "$env:TEMP\zhiwei-boundary-results.json"
```

脚本从自身位置查找项目，因此不依赖特定用户名、盘符或本机绝对路径。运行环境需包含项目依赖；不需要另行启动服务。

| 边界 | 检查条件与预期 |
| --- | --- |
| 批量上传 | 10 个内容不同的有效 TXT 成功；11 个文件被拒绝且不增加资料 |
| 文件大小 | 实际 20 MiB（20,971,520 字节）的有效 PDF 成功并提取文本；大 1 字节的文件被拒绝 |
| 用户名长度 | 2、32 个 ASCII 字符成功；1、33 个字符被拒绝 |
| 密码长度 | 8、128 个 ASCII 字符成功；7、129 个字符被拒绝 |
| 问题长度 | 空知识库接受 2000 个字符的问题，返回资料不足并保存两条消息；2001 个字符被拒绝且不写入消息 |

20 MiB PDF 为脚本现场构造的单页文本 PDF：在交叉引用表之前加入无害空白，同时保持正确的对象偏移和索引。它验证实际上传字节上限，并非大篇幅 PDF 的解析性能测试；没有模拟或缩小文件大小常量。现有 28 项测试中的快速超限检查使用了缩小后的常量，本脚本补充实际文件大小和接受端点。

每次运行只使用 `TemporaryDirectory` 内的新 SQLite 数据库和合成资料，检查后清理；不读取用户知识库，不改变项目 `data/`，不调用外部模型。脚本内凭据均为临时测试值；JSON 结果仅含检查条件、状态、错误提示和汇总，不保存密码、密钥、用户文件内容或本机目录。

这组检查不覆盖 200 万字符提取上限、2000 页 PDF 上限、扫描件/加密 PDF、真实模型服务、检索质量、性能或并发；不能据此宣称所有边界或非功能需求均已验收。
